# WB Real Stock Bot v2

Обновлённая версия бота с обработкой `403 Forbidden` от `card.wb.ru`.

## Что изменилось

- Добавлен `WB_STOREFRONT_PROXY`.
- Прокси используется только для запросов к покупательской витрине WB.
- Seller API продолжает ходить напрямую.
- `403` от витрины больше не валит выгрузку traceback-ом в Telegram.
- Бот сообщает, что IP сервера заблокирован и нужно настроить прокси/другой сервер.
- Добавлены более браузероподобные заголовки для storefront-запросов.

## Настройка

Скопируйте `.env.example` в `.env`.

Пример:

```env
TELEGRAM_BOT_TOKEN=...

WB_CABINET_1_NAME=Кабинет 1
WB_CABINET_1_TOKEN=...

WB_CABINET_2_NAME=Кабинет 2
WB_CABINET_2_TOKEN=...

WB_DEST=-1257786

# Если без прокси card.wb.ru = 403:
WB_STOREFRONT_PROXY=http://login:password@host:port
```

Если прокси без авторизации:

```env
WB_STOREFRONT_PROXY=http://host:port
```

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

## Что проверять первым

Нажмите:

**🧪 Проверить контрольные артикула**

Ожидается:

- 16358648 → 0
- 219205510 → 0
- 206008365 → 4

Если цифры отличаются, сначала проверяйте `WB_DEST`.

## Важно

`card.wb.ru` — это покупательская витрина, а не официальный Seller API. WB может блокировать датацентровые IP. Поэтому для определения именно "что реально доступно клиенту" иногда нужен прокси или другой серверный IP.
